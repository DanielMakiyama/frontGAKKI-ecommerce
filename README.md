# GAKKI STORE — Frontend

Frontend simples (React + Vite) para demonstrar o fluxo completo da loja
consumindo a API REST do backend Java. Veja o README na raiz do projeto
para instruções completas de execução.

```bash
cp .env.example .env   # ajuste VITE_API_URL se o backend não estiver em localhost:8080
npm install
npm run dev
```
